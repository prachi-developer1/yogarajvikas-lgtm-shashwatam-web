# Shashwatam – Spiritual & Donation Platform

## About the Project

**Shashwatam** is a web-based platform designed to connect devotees with Swamiji's spiritual initiatives. The platform aims to provide a convenient way for users to learn about spiritual activities, contribute donations, and participate in supported investment-related initiatives.

The project focuses on providing a simple, accessible, and user-friendly digital experience for devotees and supporters.

## Key Features

- **Donation Management** – Enables devotees to contribute financial donations to supported spiritual activities.
- **Investment Initiatives** – Provides information about available investment opportunities or initiatives, where applicable.
- **Devotee Engagement** – Helps users stay connected with Swamiji's activities and initiatives.
- **User-Friendly Interface** – Simple and intuitive navigation for users.
- **Responsive Design** – Supports access across desktop, tablet, and mobile devices.
- **Secure Transactions** – Designed to support secure handling of donations and financial transactions, subject to the implemented payment and security systems.

## Getting Started

Follow these steps to run the project locally.

### Prerequisites

Make sure the following tools are installed:

- Node.js
- npm (Node Package Manager)
- Angular CLI, if required
- Visual Studio Code or another code editor

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/yogarajvikas-lgtm/shashwatam-web.git
```

**2. Navigate to the project directory**

```bash
cd shashwatam-web
```

**3. Install dependencies**

```bash
npm install
```

**4. Run the application**

```bash
npx ng serve --open
```

The application will usually run at:

http://localhost:4200/
